ROOKie[팀 프로젝트]

ROOKie는 두 단계의 프로젝트를 통해 야구 팬덤의 일상 속으로 깊숙이 스며들어 새로운 팬 경험의 중심이 되는
커머스와 OTT를 아우르는 야구 통합 플랫폼으로 확장되었습니다.

🎲

주요 기능 및 특징

  • 로그인 회원가입 마이페이지파트를 담당하여 사용자 정보를 관리
  • ROOKie 사이트 내에 전체적인 Firebase database 담당하여 전체 팀원들의 데이터 베이스 관리에 도움을 줌
  • Zustand와 Firebase Authentication이 전역에서 세션을 관리
  • persist 미들웨어로 새로고침 후에도 상태를 유지해 끊김 없는 팬 활동을 보장
  • 마이페이지에서 일반 사용자는 ROOKie 파트너를 신청할 수 있고, ROOKie 파트너 사용자는 상품등록 요청을 할 수 있음
  • 쇼핑 관련 현황과, 내가 좋아요한 동영상을 확인
  • 팀의 디자이너로서 PPT, 사이트 로고, 구조적 디자인 총괄
💬

  • 회원가입 데이터를 브라우저 로컬 스토리지에 자동 저장되도록 설계

Fullpage Customizing[개인 프로젝트]

fullPage.js 라이브러리를 사용해 제작된 반응형 웹사이트입니다. 사용자는 스크롤을 내리는 것만으로도 부드럽게 다음 섹션으로 이동할 수 있습니다.

📄

주요 기능 및 특징

  • fullPage.js 라이브러리를 이용하여 스크롤 시 페이지 전체가 한번에 전환되는 사용자 경험을 제공합니다.
  • anime.js 라이브러리를 이용하여 각 섹션이 로드될 때마다 동적인 애니메이션 효과를 부여하여 시각적 즐거움을 더했습니다. 예를 들어, 첫 섹션에서는 SVG 패스 애니메이션이, 두 번째 섹션에서는 기술 숙련도를 나타내는 막대 그래프가 동적으로 채워집니다.
  • 상단 GNB(Global Navigation Bar) 메뉴를 통해 사용자가 원하는 섹션으로 빠르게 이동할 수 있도록 설계했습니다.
💬

Netflix clone coding[개인 프로젝트]

넷플릭스 홈페이지를 클론 코딩하여 사용자에게 영화 정보를 제공하고, 웹 개발 기술을 연습하기 위해 제작되었습니다.

🎬

주요 기능 및 특징

  • TMDB API를 활용해 현재 상영작, 개봉 예정작, 인기 상영작 데이터를 실시간으로 가져와 화면에 표시합니다.
  • fetch와 async/await을 사용하여 비동기적으로 데이터를 처리하고 Promise.all을 통해 여러 API 호출을 효율적으로 관리합니다.
  • Vanilla JS로 무한 슬라이드 기능을 구현하여 사용자가 영화 목록을 부드럽게 넘겨볼 수 있습니다. 슬라이드 너비, 간격, 이동 거리를 계산하여 동적으로 움직이도록 설계했습니다.
  • 각 영화 포스터를 클릭하면 해당 영화의 상세 정보(줄거리, 장르, 개봉일, 예고편 등)를 보여주는 모달 창이 나타납니다.

풀페이지 스크롤 효과와 부드러운 전환 효과를 적용하여 사용자가 모든 콘텐츠를 직관적이고 몰입감 있게 한 페이지에서 경험할 수 있도록 설계했습니다.

🎲

주요 기능 및 특징

  • 각 섹션(홈, 어바웃, 프로젝트, 플랜, 어워드, 로케이션, 컨택트)이 풀스크린으로 표시되며, 사용자가 스크롤을 통해 다음 섹션으로 부드럽게 전환할 수 있습니다.

Onebite sky[개인 프로젝트]

이 프로젝트는 Next.js 프레임워크를 기반으로, 도서 관련 데이터를 표시하는 웹 애플리케이션입니다.

📚

주요 기능 및 특징

  • Node.js 위에서 동작하며, 효율적인 서버 개발을 위해 모듈화된 아키텍처를 제공합니다.
  • SSR (Server-Side Rendering): 요청이 들어올 때마다 서버에서 페이지를 생성하여 사용자에게 최신 데이터를 제공합니다.
  • SSG (Static Site Generation): 빌드 시점에 HTML을 미리 생성하여 CDN에 배포합니다. 데이터가 자주 변하지 않는 페이지에 적합하며, 로딩 속도를 보장합니다.
  • ISR (Incremental Static Regeneration): SSG의 장점에 동적인 업데이트 기능을 더한 방식입니다. 미리 생성된 페이지를 사용하면서도, 정해진 시간마다 또는 데이터가 변경될 때마다 페이지를 백그라운드에서 재빌드하여 항상 최신 정보를 유지할 수 있습니다.
