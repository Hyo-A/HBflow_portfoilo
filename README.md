📂 주요 프로젝트 목록
포트폴리오에 포함된 대표 프로젝트들을 간결하게 소개합니다.

1. Onebite sky (도서 웹 애플리케이션)
핵심 기술: Next.js, TypeScript, Prisma, Vercel

특징: SSR, SSG, ISR 등 다양한 렌더링 전략을 적용하여 페이지 로딩 속도를 최적화했습니다.

2. ROOKie (커뮤니티/쇼핑몰)
핵심 기술: React, Firebase, Zustand

특징: 사용자 인증(Authentication) 및 데이터베이스 기능을 포함한 풀스택 프로젝트입니다.

3. 목으로 말해요 기롱이 (이모티콘 디자인 & 굿즈 기획)
특징: 기린을 모티브로 감정을 표현하는 캐릭터입니다. 캐릭터 기획부터 이모티콘 시안 및 머그컵, 양말 등 응용 굿즈 디자인까지 진행했습니다.

4. 학과별 캐릭터 (강릉중앙고)
특징: 학교의 상징 동물인 호랑이를 활용하여 5가지 학과 캐릭터를 디자인했습니다. **고객과 소통하여 기획부터 실제 굿즈 제작(스티커, 종이컵)**까지 완료한 상업 프로젝트입니다.
