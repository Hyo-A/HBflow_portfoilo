### HELLO!
제품을 만들고, 서비스를 제공함에 있어서 즐거움을 느껴왔습니다.
이제는 사용자와의 직접적인 상호작용이 필요한 UX&UI를 제작함을 원하고있고, 팀원들과 함께 작업했던 프로젝트에 애정을 가지고 있습니다.
프론트앤드 공부를 한 기간은 길지 않지만, 빠르게 성장하였고 알찬 경험을 하였다 자부합니다. 써보지 않았던 프레임워크나 라이브러리를 공부하며 다양한 작업을 해보고싶습니다.
지금 보여드리는 작업물에 그치지 않는 더욱 멋진 프로젝트를 만들어가겠다 약속드립니다.
